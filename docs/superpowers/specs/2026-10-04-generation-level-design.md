## 1. 目的と範囲

### 1.1 背景

2026-10-04 の毎日王冠で、人気の3歳3頭（リアライズシリウス・ライヒスアドラー・アドマイヤクワッズ）が
5・7・17着に敗れた。所有者の見立ては「データ上は3歳が強いが、今の3歳世代は弱く、4・5歳世代のレベルが高い」。

今の統計モデル（P v3 の能力 `ab`）は「同じレースで誰に先着したか」をつなぎ、0 に寄せるリッジで推定している。
3歳は6月まで、2歳は年内ずっと同世代としか走らないので、**世代全体の強さは推定の構造上「平均」に寄せられ、
モデルに入らない**。本仕様はこの穴を埋める単体の指標を作り、所有者の仮説を調べる。

## 3. タイム指数

### 3.1 対象とする走

- JRA10場（`jyo_cd` 01〜10）の平地（`track_kind` が turf / dirt）。障害は除く
- 確定成績（`data_kubun` 7。同じレースに複数の区分があれば既存の `_pick_by_data_kubun` の優先順位に従う）
- `result_ijyo_cd` が `config.IJYO_EXCLUDED` に入る走（取消・除外・中止など）と、走破タイムが空・0 の走は除く
- 発走時刻が `as_of` より前のレースだけ

### 3.2 基準タイム・クラス差・馬場差の推定

**古馬戦だけ**から推定する（§3.4）。各古馬戦の1着の走破タイムを 1000m あたりの秒 `y = time_sec / (kyori_m / 1000)` にして、

```
y_race = s[キー] + c[クラス, track_kind] + v[開催面] + e
```

- `s`: キーごとの基準（1000m あたり秒）
- `c`: クラス差。`config.class_level` の値（0〜8）× 芝ダ。基準は 2（1勝クラス）で `c = 0`
- `v`: 開催面ごとの馬場差。**経験ベイズの縮小**をかける。残差の分散 σ² と開催面間の分散 τ² をモーメント法で
  推定し、`v̂ = Σ残差 / (n + σ²/τ²)` とする（n はその開催面の古馬戦の数）。`s` と `c` は縮小しない
- `s, c` と `v` は交互に推定して収束させる（`v` を固定して `s, c` を最小二乗、`s, c` を固定して `v` を縮小推定）
- クラスが決まらないレース（`class_level` が None）は推定に使わない

### 3.3 走ごとの指数

すべての対象の走（2歳戦・3歳戦を含む）について、

```
figure = (s[キー] + v[開催面] − time_sec / (kyori_m / 1000)) × 1.6
```

単位は **1600m 相当の秒**。正ほど速い。クラス差 `c` は足さない（1勝クラスの水準を基準にした絶対の物差し）。

- キーが古馬戦に無い（`s` が無い）走は指数を出さない（欠損）。レポートに件数と割合を出す
- 開催面に古馬戦が無い走は `v = 0`（縮小の事前の値）とし、件数をレポートに出す

### 3.4 なぜ古馬戦だけで推定するのか

2歳戦・3歳戦を推定に混ぜると、「今年の2歳が弱い（遅い）」ことが「その日の馬場が遅かった」として
馬場差 `v` に吸収され、世代差が消える。古馬戦は複数の世代が混ざるので、1つの世代の強弱が `v` に与える影響は
薄まる。**この性質はテストで確かめる（§9）**。

### 3.5 物差しは1つ

基準タイム・クラス差・馬場差は、`as_of` より前の全データで**1回だけ**推定し、過去の年の走にも同じ物差しを当てる。
年ごとに作り直すと年どうしの比較がずれるため。

### 3.6 指数の再現性の確認

同じ馬の続けて2走（間隔 120 日以内）の指数の相関係数をレポートに出す。相関が弱ければ、指数は展開や運の
ぶれが大半ということになる。合否の線は引かず、値をそのまま示す。

## 4. 世代の数値（§5 の共通部品）

年 Y の月日 md の時点で、世代 g（年齢 a = Y − g）について:

1. Y 年 1/1 から時点の前日までの対象の走のうち、世代 g の馬の走を集める
2. 馬ごとに指数の**最高値**を取る
3. 最高値を高い順に並べ、次の3つを世代の数値とする

| 数値 | 意味 |
|---|---|
| `top10` | 上位10頭の平均。世代の頂点（重賞級） |
| `top50` | 上位50頭の平均。オープン〜重賞の層の厚さ |
| `median` | 指数を持つ全頭の中央値。世代全体の底 |

- 頭数が K に満たないときの `topK` は欠損にする
- 過去の年の時点は `as_of` と同じ月日（2/29 は 2/28）。**比べてよい年**だけを使う

## 5. 世代の比較

### 5.1 比べられる世代の数（2026-10-04 時点、5年版）

比べてよい年は 2022〜2026年。各年齢で比べられる過去の世代は 2022〜2025年の4つ（2歳: 2020〜2023年生まれ、
3歳: 2019〜2022年生まれ、4歳: 2018〜2021年生まれ、5歳: 2017〜2020年生まれ）。

### 5.2 例年比（仮説①。全年齢）

今年の世代を、過去の世代の**同じ年齢・同じ月日の時点**と比べる。

- 出すもの: 世代ごとの3つの数値、過去の世代の平均、今年の世代 − 過去の平均 とその95%区間、過去の世代の中での順位
  （今年を含めた中での順位。1 が最強。同値は同じ順位）
- 比べる相手には名前を付ける。例: 3歳の表では「今の4歳（2022年生まれ）の3歳時」「今の5歳（2021年生まれ）の3歳時」
- 2歳は**この比較だけ**で評価する

### 5.3 今いる世代の並び（見立ての照合。3歳以上だけ）

時点 `as_of` の年の3歳以上の世代を、§4 の数値で直接並べる（指数は年齢をまたいで同じ物差し）。

- **2歳はこの表に入れない。** 2歳と3歳以上は実力差が大きすぎ、並べても比較にならない（所有者の判断）
- 世代の組ごとの差（4歳 − 5歳、5歳 − 3歳、4歳 − 3歳）を、次の通りに出す
  - **例年の差と比べた差（判定に使う）**: §5.2 の例年比の差 `例年比[a] − 例年比[b]`、つまり
    （今年の a − 過去の a の平均）−（今年の b − 過去の b の平均）。過去の平均は年齢ごとに欠損を除いて取る。
    両方の年齢が同じ過去の年（比べてよい年）を使うので、過去のどの年にも両方の値があれば「今年の組の差 − 過去の年ごとの
    同じ組の差の平均」と一致する。片方だけが欠損の年があると一致しない（その年は欠損でない側の平均にだけ入る）。95%区間付き
  - **今年のそのままの差（参考）**: 95%区間付き。判定は付けない
  - **例年の差（参考）**: 過去の a の平均 − 過去の b の平均（欠損が無ければ過去の年の同じ組の差の平均と同じ）
  - **年齢分を差し引いた差（参考）**: §6 の年齢曲線で、その時点の年齢から見込まれる差を引いたもの。95%区間付き。判定は付けない
- 参考の差に判定を付けない理由（レポートに1行で書く）: 年齢曲線は同じ馬の加齢しか除かない。4・5歳は弱い馬が
  引退した後の集団で、3歳は未勝利馬まで含む集団なので、生き残り・顔ぶれの差が残る。3歳の斤量の減量の分と、
  年の途中の時期のずれ（3歳の最高値は3歳前半に出やすい）も残る。これらは毎年ほぼ同じ形で出るので、
  そのままの差・年齢分を差し引いた差で判定すると毎年「見立てと合う」になる（2022〜2025年の 4歳 − 3歳 の中央値の差は
  毎年 +1.1〜+1.4）。例年の差と比べた差は、年ごとに変わらない偏りを丸ごと除き、「今年の並びが例年と違うか」に直接答える
- 過去の年の同じ月日の並びを `top10` / `top50` / `median` の3つとも添える（年 × 3歳以上の年齢）
- 照合（例年の差と比べた差の区間で決める）: 区間が 0 を含まず見立ての向き →「見立てと合う」、区間が 0 を含まず逆向き →
  「見立てと逆」、区間が 0 を含む →「差があるとは言えない」、区間か差が欠損（頭数不足など）→「判定できない」。
  `top10` / `top50` / `median` で結論が割れたら、割れたことをそのまま書く

### 5.4 世代の歩み（仮説②）

時点の年に3歳以上である各世代について、**その世代が2歳・3歳・4歳……だった年の同じ月日の時点**の数値を
§5.2 と同じ例年比（その年齢の他の世代の平均との差）で並べる。

| 世代 | 2歳時 | 3歳時 | 4歳時 | 5歳時 |
|---|---|---|---|---|
| 2022年生まれ（今の4歳） | 2024年の例年比 | 2025年の例年比 | 2026年の例年比 | — |

- 比べてよい年でない年齢の欄は空にする
- 年齢を重ねても例年比の符号と大きさが保たれるか（世代の地の差か）を見る。数字として、隣り合う年齢の組 (a, a+1)
  ごとに、`top10` の例年比の a 歳時と a+1 歳時の相関係数を、世代をまたいで出す（比べてよい年にある全世代のうち、
  両方の年齢に値がある世代。今いる世代に限らない）。使った世代の数を添え、3世代未満なら相関は出さない。
  世代の数が少ないので**記述**にとどめ、証拠としては扱わない（レポートにそう書く）

### 5.5 95%区間

ブートストラップ。既定 200 回、乱数の種は固定（`--seed`、既定 20261004）。複製ごとに次の3段で作り、
2.5% と 97.5% の分位点を区間とする（パーセンタイル区間）。

1. **物差しの誤差**: 開催日（日付）を復元抽出し、選ばれた日のレース（古馬戦の1着）で §3.2 の推定をやり直す。
   同じ日が2回選ばれたら別の日として扱う
2. その物差しを**元の走すべて**に当てて指数を付け直す。複製に選ばれなかった日の開催面の馬場差と、複製に古馬戦が
   無かったキーの基準タイムは、点推定の物差しの値を使う（どの走も、抽出のせいで指数を失わない）
3. **顔ぶれの誤差**: 世代ごとに馬を復元抽出する。馬の全走（年をまたいでも）をまとめて動かし、2回選ばれた馬は
   別の馬として数える。これに §4〜§5 の計算をする

当初は「抽出した日の走だけに指数を付けて §4〜§5 を計算」していたが、復元抽出では約 37% の日が選ばれないので
馬ごとの走が減り、最高値・上位K頭の平均・中央値が下に偏った（2026-10-04 の実データで、世代の数値の区間 60 個のうち
34 個が点推定を含まず、すべて上側に外れていた）。手順 2・3 はこれを避けるため。

年齢分を差し引いた差（§5.3）の区間では、年齢曲線の水準は点推定に固定する（曲線の誤差は区間に入らない）。

## 6. 年齢曲線（仮説③）

### 6.1 測り方: 同じ馬の変化

年齢ごとの全体の平均を並べると、弱い馬ほど早く引退するので、高齢ほど強く見える（生き残りの偏り）。
そこで**同じ馬の、隣り合う期間どうしの変化**を測る。

- 期間は**半年**: 前半（1〜6月）と後半（7〜12月）。年齢と合わせて「3歳前半」「3歳後半」「4歳前半」…と呼ぶ
- 馬の期間の値 = その期間の指数の**上位2走の平均**。2走以上ある期間だけ使う
  （最高値1つだと、走った回数が多い期間ほど高く出るため）
- 変化 = 次の期間の値 − 前の期間の値。両方の期間に値がある馬だけ
- 期間の変化の平均を年齢順に積み上げて曲線にする。基準は **3歳後半 = 0**
- **芝・ダート別**にも出す（その期間の芝の走だけ／ダートの走だけで期間の値を作る）。全体の曲線は芝ダを混ぜた走で作る
- 使う期間は、比べてよい年の中で**期間が終わっている**ものだけ（`as_of` の年の途中の期間は使わない）

### 6.2 出すもの

- 半年ごとの変化の平均、頭数、95%区間（馬単位のブートストラップ。既定 200 回、§5.5 と同じ種）
- 積み上げた曲線と、**全盛期**、全盛期から1年後（2期間後）の落ち幅
  - 全盛期の候補は頭数（その期間への変化を持つ馬の数）**30 以上**の期間だけ。高齢の数頭の期間は偶然高く出るため
  - 水準の最大の期間を1つ挙げるだけでは、曲線が平らなとき精度を装うことになる。最大の期間と、水準の95%区間が
    最大の期間の区間と重なる期間（頭数 30 以上）を「横ばい」として示す（例:「3歳後半〜5歳前半でほぼ横ばい、
    最大は 4歳前半 +0.09」）。間に重ならない期間を挟むときは「横ばい」と書かず並べる
  - 1年後の落ち幅は、2期間後の頭数も 30 以上のときだけ出す
  - 曲線の表では頭数 30 未満の期間に「頭数少」と付ける
- 芝・ダート別の同じもの

### 6.3 既知の偏り

同じ馬で測っても、大きく衰えた馬はそのまま引退して次の期間の値を持たないので、**衰えは小さめに出る**。
レポートに明記する。

| `figures.csv` | 走ごとの指数（race_id, umaban, ketto_num, 世代, 年齢, 指数, キー, 開催面） |
| `manifest.json` | 使った版の id、`--data-dir`、比べてよい年を決めた取得開始日、`as_of`、引数、推定した σ²・τ²、実行時刻 |

レポートには毎日王冠（2026-10-04）を**例**として載せる: 出走馬の世代と、10/4 時点の各世代の例年比。
**精度の証拠としては扱わない**（結果を見てから作った指標なので）。見出しにはレース名（races.csv の `race_name`。
データ区分は問わず、作成日が最も新しい行）を付ける。比べる年齢（`--ages` の最大）より上の馬は比べない（—）と注記する。

## 9. テスト

作り物の小さなデータで、**テストを先に書いてから実装する**。

| テスト | 確かめること |
|---|---|
| 馬場差の回収 | 開催面ごとに仕込んだ馬場差を、推定で（縮小の分を除いて）取り戻せる |
| **2歳の遅さが吸収されない** | 2歳戦の時計だけを一律に遅くしても馬場差は変わらず、2歳世代の指数が下がる（§3.4 の核心） |
| `as_of` | `as_of` 以降のレースは基準タイム・馬場差の推定にも指数にも一切使われない |
| 除外 | 障害戦、取消・除外・中止、タイムが空の走は除かれる |
| 欠損 | 古馬戦に無いキーの走は指数が欠損になる |
| 上位K頭 | 馬ごとの最高値と `top10` / `top50` / `median`、K 頭未満の欠損 |
| 同じ月日 | 過去の年の時点が同じ月日になる。2/29 は 2/28 |
| 比べてよい年 | coverage が年の途中から始まる年は比較に入らない |
| 2歳は並びに入らない | §5.3 の表に2歳の世代が入らない |
| 世代の歩み | 世代 g の a 歳時が g + a 年の値になる。比べてよい年でない欄は空 |
| 年齢曲線 | 仕込んだ年齢ごとの伸び・衰えを、同じ馬の変化から取り戻せる。1走しかない期間は使われない。途中の期間は使われない |
| 生き残りの偏り | 弱い馬だけが途中で引退する作り物でも、同じ馬の変化で測れば仕込んだ曲線に近い（全体平均の方法より偏りが小さい） |
| 全盛期 | 頭数 30 未満の期間は候補にならない。区間が重なる期間が横ばいとして並ぶ。2期間後の頭数が足りなければ落ち幅は欠損 |
| 例年の差と比べた差（端から端まで） | 地力 + 真の年齢曲線 + 弱い馬の引退を、毎年同じ構造で作った作り物を age_curve → cohort_table → 組の差に通す。年齢曲線は正しく取れ、年齢分を差し引いた差は 0 にならない（生き残りの偏りが残る）が、例年の差と比べた差は 0 になり、判定は「差があるとは言えない」 |
| 世代の歩みの相関 | 世代の地の差がそのまま残る作り物で相関が 1。3世代未満は欠損 |
| 区間の再現 | 同じ種なら同じ区間になる |
| 区間の偏り | 馬が開催日の一部にしか走らない雑音の大きい作り物で、点推定が区間に入り、複製の平均が点推定から 0.08 秒以内。以前の手順（抽出した日の走だけに指数を付ける）は同じ検査で落ちる |
| 照合の判定 | 区間と向きから3通りの判定が正しく出る。レポートの判定は例年の差と比べた差の区間から出る |

## 10. 第2段階の方針（参考。別の仕様で決める）

所有者の目的は「世代の情報で予想の精度が上がるか」を確かめること。第1段階の結果を見てから別の仕様にするが、
次の点は合意済みの方針として残す。

- **毎日王冠1レースでは判断しない。** 結果を見てから足した材料なので、証拠にならない
- 対象は3歳と古馬が一緒に走る混合戦（6〜12月）と、年末の2歳戦
- 物差しは的中数ではなく確率の当たり具合（対数損失）。今のモデル（市場＋統計）に世代の値を足して比べる
- **判定の方法を先に固定し、2026年10月中旬以降のこれからのレースで検証する。** 2026年1〜9月は統計分析の
  一度きりの検定（第6報）で使用済み
- 世代の値は1世代に1つなので、実質のデータ点は世代の数（5〜6）しかない。「判断できない」で終わる可能性が高い

## 11. 既知の弱点

- スローペースのレースは時計が遅く出る。馬ごとの最高値・上位2走を使うことで和らげるが、消えはしない
- 斤量は補正しない。同じ年齢どうしの比較が主なので影響は小さい。ただし §5.3 の3歳と古馬の並び（そのままの差・
  年齢分を差し引いた差）では、3歳の減量の分だけ3歳が有利に出る。判定に使う例年の差と比べた差では、減量の規則が
  年ごとに変わらない限り消える
- 区間は物差しの誤差と馬の顔ぶれの誤差を含むが、年齢曲線の誤差は含まない（§5.5）
- 世代の数が少ない（過去4世代）ので、例年比の「過去の平均」は粗い
- 古馬戦にも3歳（6月以降）が混ざるので、3歳世代の強弱はわずかに馬場差へ漏れる
- 年齢曲線は衰えを小さめに出す（§6.3）
